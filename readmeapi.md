# مستندات API پروژه TrelloJiraCore

این سند شامل جزئیات فنی تمام نقاط انتهایی (Endpoints) و هاب SignalR برای مدیریت پروژه است.

## پایه آدرس API
`http://localhost:5000/api`

## بوردها (Boards)

### دریافت تمام بوردها
- **آدرس:** `/boards`
- **متد:** GET
- **پاسخ موفق (200):** لیستی از بوردهای موجود.

### دریافت جزئیات یک بورد
- **آدرس:** `/boards/{id}`
- **متد:** GET
- **پاسخ موفق (200):** آبجکت کامل بورد شامل لیست‌ها و کارت‌های مرتب شده.

### ایجاد بورد جدید
- **آدرس:** `/boards`
- **متد:** POST
- **بدنه درخواست:**
```json
{
  "title": "عنوان بورد",
  "description": "توضیحات بورد"
}
```

## کارت‌ها (Cards)

### جابه‌جایی کارت
- **آدرس:** `/cards/{id}/move`
- **متد:** PUT
- **بدنه درخواست:**
```json
{
  "toListId": 2,
  "newOrder": 0
}
```
- **توضیحات:** این عملیات باعث بروزرسانی دیتابیس، ثبت در تاریخچه فعالیت‌ها و ارسال پیام به هاب SignalR می‌شود.

## مستندات SignalR Hub

### آدرس هاب
`ws://localhost:5000/boardHub`

### متدها (Client to Server)
1. `JoinBoard(int boardId)`: برای عضویت در یک بورد خاص جهت دریافت بروزرسانی‌های آنی.
2. `LeaveBoard(int boardId)`: برای خروج از بورد.

### رویدادها (Server to Client)
1. `OnCardMoved(int cardId, int fromListId, int toListId)`: زمانی که کارتی توسط کاربری جابه‌جا شود، به تمام اعضای آنلاین بورد اطلاع داده می‌شود.
2. `OnCardUpdated(int cardId)`: زمانی که محتوای کارتی ویرایش شود.
